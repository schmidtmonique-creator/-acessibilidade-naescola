
# ♿ Acessibilidade na Escola

## Sobre o projeto

Este projeto apresenta informações sobre como tornar o ambiente escolar mais acessível para todos.
A página foi desenvolvida com cards informativos que abordam comunicação, ambiente, informação, orientação, linguagem e rotina.
O objetivo é conscientizar sobre a importância da inclusão e da acessibilidade nas escolas.
O site possui um design simples, organizado e adaptável para computadores e celulares.

## Tecnologias

- HTML5
- CSS3
- GitHub
- GitHub Pages

## Práticas de acessibilidade

- Textos simples e fáceis de compreender.
- Contraste adequado entre texto e fundo.
- Fonte legível.
- Organização das informações em cards.
- Espaçamento entre os elementos.
- Estrutura HTML semântica.
- Uso de títulos organizados.
- Botão com identificação clara.
- Navegação por teclado com destaque de foco.
- Layout responsivo para celulares.
